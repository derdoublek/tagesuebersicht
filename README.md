# Tagesübersicht

Persönliches Tages-Dashboard: Termine aus Google Kalender, offene Google Tasks und unbeantwortete Mails aus mehreren Gmail-Konten in einer Übersicht.

- Läuft komplett im Browser, ohne Server. Daten werden direkt bei Google abgerufen und nirgends gespeichert.
- Konten werden beim ersten Start in der App eingetragen und nur lokal im Browser gespeichert.
- Unterseiten: `#/kalender`, `#/aufgaben`, `#/mails`
